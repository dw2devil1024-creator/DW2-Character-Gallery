# DW2 · Character Gallery

**DW2 · Character Gallery** ｜ 角色画廊  
**S.A. · DW2**

一款面向 **TauriTavern / SillyTavern** 原生角色列表的独立视觉扩展。与 [DW2 · Story Archive](https://github.com/dw2devil1024-creator/dw2-story-archive) 使用同一组冰蓝、雾粉、乳白玻璃视觉语言，但两者独立安装、独立更新。

> 画廊负责浏览和管理角色；书架负责收藏故事。

## 版本

**v1.0.3 · 分页收边精修**

## 安装

在 TT 的「安装扩展」中填写：

```text
https://github.com/dw2devil1024-creator/DW2-Character-Gallery
```

安装后重新加载 TT。默认启用画廊美化。

## 功能边界

- 仅作用于 TT 的 **角色列表**（`#rm_characters_block`），不修改角色编辑页面、Persona 页面、聊天楼层或 DW2 书架。
- 在 TT 原生**网格视图**下展示三列 3:4 封面画廊；切换到 TT 原生列表视图时，保留原版列表结构。
- 保留 TT 原生的角色点击、编辑导航、搜索、排序、分页、标签、收藏、群组/文件夹及批量选择处理逻辑。
- 不修改角色数据、头像文件、标签、聊天数据或任何原生存储键。
- 顶部「画廊模式」按钮与扩展设置页开关可随时启用/关闭美化，状态仅保存为独立的本机 `localStorage` 偏好。
- 所有改动都限定在画廊 CSS 与独立插件运行时，禁用扩展可恢复 TT 原版视觉。
- 主要使用原生角色缩略图，避免画廊单独请求大图造成额外负担。

## 测试清单

初版需在实际设备中核对：
- iPhone / Android / PC 的三列布局、图片裁切、滚动、字体及触摸反馈
- 点击角色后进入原生人设编辑页面
- 原生搜索、排序、分页、标签筛选
- 收藏标记、群组/文件夹进入与返回
- 批量选择、删除入口与多选状态
- 原生列表/网格切换、画廊/原生美化开关
- 与 DW2 · Story Archive 同时启用无样式污染

## 关于

由 **S.A. · DW2** 共同创作，保留角色数据与 TT 原生交互的完整性。

## v1.0.1 真机反馈调整

- 首屏角色卡从双列改为三列，尺寸接近 DW2 书架。
- TT 原生分页与网格/批量编辑按钮移到角色列表底部的固定工具栏，列表本身继续独立滚动。
- 修复分页按钮因错误覆盖 Font Awesome 字体而显示为方框叉号的问题。
- 新增扩展设置中的独立折叠项，与其他 DW2 插件一样显示名称与署名，提供启用美化开关。
- 不修改 TT 原生角色列表 DOM 点击链路及角色数据。

## v1.0.2 上半区重排
- 搜索与排序保持 TT 原生功能，顶栏间距更紧凑，按钮排布采用轻玻璃工具区。
- 原生筛选工具新增「筛选与整理」横向收纳栏，默认收起，展开后可以左右滑动选择；展开状态独立保存。
- 标签文件夹的返回路径保持可见，不会被收纳隐藏。
- 未复制、更换或移动 TT 筛选按钮本体，保留筛选/收藏/文件夹点击事件。

## v1.0.3 分页栏精修

- 去掉分页区域的长条深色底框，保留透明、轻量的原生底部翻页工具。
- 去除多余的 iPhone 安全区域重复内边距，让第三排角色拥有更多可见高度，并让翻页控件更靠近画廊底部。
- 缩小「50 / 页」原生下拉框（30px 高），保留 TT 翻页按钮和 select 事件。
- 放大镜保持 TT 原生的搜索栏显示／隐藏功能。
