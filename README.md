# DW2 · Character Gallery

**DW2 · Character Gallery** ｜ 角色画廊  
**S.A. · DW2**

一款面向 **TauriTavern / SillyTavern** 原生角色列表的独立视觉扩展。与 [DW2 · Story Archive](https://github.com/dw2devil1024-creator/dw2-story-archive) 使用同一组冰蓝、雾粉、乳白玻璃视觉语言，但两者独立安装、独立更新。

> 画廊负责浏览和管理角色；书架负责收藏故事。

## 版本

**v1.0.7 · 角色置顶与画廊精修**

## 安装

在 TT 的「安装扩展」中填写：

```text
https://github.com/dw2devil1024-creator/DW2-Character-Gallery
```

安装后重新加载 TT。默认启用画廊美化。

## 功能边界

- 仅作用于 TT 的 **角色列表**（`#rm_characters_block`），不修改角色编辑页面、Persona 页面、聊天楼层或 DW2 书架。
- 在 TT 原生**网格视图**下展示三列 3:4 封面画廊；切换到 TT 原生列表视图时，保留原版列表结构。
- 保留 TT 原生的角色点击、编辑导航、搜索、排序、分页、标签、收藏、群组/文件夹及批量选择处理逻辑。
- 不修改角色数据、头像文件、标签、聊天数据或任何原生存储键。
- 顶部「画廊模式」按钮与扩展设置页开关可随时启用/关闭美化，状态仅保存为独立的本机 `localStorage` 偏好。
- 所有改动都限定在画廊 CSS 与独立插件运行时，禁用扩展可恢复 TT 原版视觉。
- 主要使用原生角色缩略图，避免画廊单独请求大图造成额外负担。

## v1.0.7 角色置顶与画廊精修

- 在角色画廊每张有独立原生头像文件的角色卡右上角添加精致的独立图钉按钮，点击一次置顶，再点一次取消。点击图钉不会触发角色卡进入人物编辑。
- 置顶仅保存于本插件的独立本机 localStorage（键 `dw2cg:pinned:avatars:v1`），以 TT 原生 avatar 文件名标识角色；**不写入角色数据、收藏字段、标签或聊天记录**。不同设备间不会自动同步置顶。
- 对所有现有 TT 排序方式应用「置顶角色优先」：保留原生标签文件夹优先顺序，置顶角色内部、普通角色内部仍保留原生排序。置顶在分页之前计算，支持多页。
- 在原生「最近／最多聊天」排序下拉框增加 **「仅看置顶」** 选项，严格只显示当前 TT 原生过滤范围内已置顶的角色卡，并与原生分页联动。
- 自定义「仅看置顶」不写入 TT 的 sort_field / sort_order；切回原版视图或禁用扩展时移除自定义选项、移除图钉并恢复完整原生角色列表。
- 同步小幅降低卡片边框存在感、收紧内侧留白，不修改已经验收的三列布局、玻璃配色、顶部检索工具和底部分页。
- 角色没有独立可识别的原生头像文件名时暂不显示图钉，避免使用会因角色导入或排序变化的临时数组下标而误置顶其他角色。

**技术注意：** 为了在 TT 原生分页前完成排序，扩展只针对 `#rm_print_characters_pagination` 暂时包裹原生 jquery.pagination 初始化调用，原生回调、分页与 TT 角色数据仍由宿主控制。停用扩展时解除包裹，不修改 TT 源文件。此功能需要在 iPhone 和 Android 实测兼容性。

### v1.0.7 真机测试

1. 点击角色右上角小图钉，确认它置顶且不会打开角色详情；重复点击可取消置顶。
2. 切换「最近」「最多聊天」「A-Z」等原生排序，确认置顶一直优先且其他角色仍依原排序。
3. 选择「仅看置顶」，再切回「最近」，确认筛选、数量和翻页都正常。
4. 切到 `NATIVE VIEW`，确认原生列表和排序完全恢复；切回 `GALLERY VIEW`，图钉状态仍保留。
5. 重启 TT 确认同一台设备置顶状态保留，另一台设备因本机数据不同不会自动共享。

## v1.0.8 图钉微缩与触控优化

- 按钮实际可点击区域保持 **32px × 32px**，视觉尺寸变小但在 iPhone / Android 上更容易准确点按。
- 点击、取消置顶、置顶优先排序、仅看置顶及原生模式切换的 JavaScript 逻辑完全不变。

## v1.0.10 空白图钉再次修复

- iPhone 真机发现 v1.0.9 仍只有空玻璃方块：旧版 Font Awesome 和 SVG 图钉均未显示。
- **彻底去除图标字体与 SVG DOM**：图钉形状直接使用 CSS `::after` + `clip-path: polygon(...)` 绘制，与玻璃底框 `::before` 分开，不依赖 TT 主题的图标样式。
- 保持 22px 视觉玻璃底框、32px 触控区；置顶状态、排序和本地存储逻辑保持原样。
- 旧按钮的图标子节点会自动清理。真机是否解决仍以 iPhone/Android 测试为准。

## v1.0.11 置顶图钉稳定回退

- 根据 iPhone 真机结果，v1.0.7 图钉正确显示；v1.0.8 引入分离的玻璃伪元素后出现只有方框、没有图钉的回归，v1.0.9 / v1.0.10 的试探性替换未解决。
- **完整恢复 v1.0.7 经真机确认的图钉创建代码与图钉 CSS**；只更新了插件版本号，绝不继续在有问题的样式结构上叠加新补丁。
- 图钉可见按钮回到 **26px × 26px**，没有额外 `::before` 玻璃层，没有 `::after` 拼图，也没有 SVG。字体图钉的结构与 v1.0.7 一致。
- 置顶数据仍留在原本的独立 localStorage key，排序、仅看置顶与原生模式切换逻辑保持 v1.0.7。
- **注意：** 本次做的是严格的已知正常版本回退。之后若继续追求更小图钉，应单独验证新样式，避免再次破坏真机显示。

## v1.0.12 画廊置顶性能修复

- 对 v1.0.7 新增的图钉装饰过程去重：在 1000/页等大页面中，先获取一次 TT 角色集合，再逐卡读取。避免每张卡反复调用 `SillyTavern.getContext()`。
- 图钉样式严格保留已通过真机测试的 v1.0.7 / v1.0.11 外观（26px）；其余排序、分页、存储及模式切换逻辑不变。
- 优化是代码级性能改进，并非承诺完全消除所有设备卡顿；请以真实操作对照测试。

## v1.0.13 置顶顺序与轻量点击

- **置顶队列按用户点击时间排列**：第一个置顶的固定排第一，后续置顶依次排后面；取消再置顶会进入队尾。非置顶角色继续保持 TT 的原生排序。现有置顶集合在 localStorage 中本来按点击顺序保存，本次直接使用它，无需迁移或重设。
- 「仅看置顶」也按相同的置顶先后顺序显示。
- 对 **单页装得下全部角色的纯角色画廊**，点击图钉时使用 CSS Grid `order` 重新排列原有卡片，免去原来的整页 `printCharacters(true)`、筛选重绘、分页重新初始化及滚动位置重置。
- 多页、包含文件夹或群聊的列表，以及「仅看置顶」仍走 TT 原生刷新，保证列表完整和分页正确。
- 切换原生模式或停用扩展时清除临时 CSS 顺序。保留原版已验证成功的 26px 小图钉外观、点击事件、置顶存储。

## v1.0.14 · 启动性能隔离

- TT 启动时不再提前调用原生 `printCharacters(true)`，取消画廊启动阶段的多重完整角色列表刷新。
- 不再监听整个 document.body 的子节点变动。仅监听 TT 原生角色抽屉 `#right-nav-panel` 的开关，以及 `#rm_characters_block` 的可见状态；**第一次真正打开角色画廊**才装配界面并触发一次原生角色列表刷新。
- 后续打开已构建好的画廊直接复用，只有在画廊隐藏期间更换原生/美化模式时才标记下一次打开需要刷新。
- 移除重复的在线 Google Fonts CSS `@import`，沿用当前 TT 主题已加载的字体或系统衬线字体。
- 保持原来的本地置顶存储键、置顶先后排名、单页快速置顶、原生分页桥、仅看置顶及卡面 **26px 图钉**。不修改书架插件。
- 检查重点：首次进入画廊、切换原生视图、图钉与仅看置顶、多页排序、重新启动后书架首页加载速度。

此项针对明确的启动浪费进行修复；实际速度变化需用 iPhone/安卓冷启动对比测试确认。
